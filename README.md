# Bloop — a common room for the internet

Bloop is a relaxing social hub: read, play, listen and hang out together in live rooms.

Live site: https://bloop-common-room.netlify.app

## What is in this repo

- `index.html` — the whole app (single file: reading rooms, 20 games, live rooms with voice + chat, Listening Party, people matching)
- `manifest.webmanifest` + `sw.js` + `icon-192.png` / `icon-512.png` / `icon-512-maskable.png` — installable PWA files

## Run it

Serve the folder with any static host (or open `index.html` directly for a quick look). Accounts and live rooms use Supabase (Realtime + Auth); the key in the file is the public publishable key.

## Status

The app is live and in active use. Fixes land here as the site is updated.
